# Game of Life

Game of Life is an interactive simulation of Conway’s Game of Life, featuring a React + Vite frontend and a C++ core compiled to WebAssembly using Emscripten.  
It allows users to explore cellular automaton behavior in real time while showcasing the integration of native C++ logic with modern web technologies.

## Features

- Real-time simulation of Conway’s Game of Life
- Core simulation logic written in C++ and compiled to WebAssembly
- Interactive grid with drawing and editing controls
- Play, pause, step, and reset simulation states
- Adjustable simulation settings for experimentation
- Responsive and modern UI built with React

---

## Built With

- Frontend: React, TypeScript, Vite
- Core Logic: C++
- WebAssembly: Emscripten
- Styling: CSS Modules
- Deployment: GitHub Pages

---

## Background

This project began as a C++ desktop application built with wxWidgets.  
It was later recompiled to WebAssembly, allowing the original C++ logic to run directly in the browser with a modern React-based interface.
